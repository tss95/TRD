# Learning Event Representations by Localizing Temporal Reversals

Temporal Reversal Discrimination (TRD) reverses one interval of a time-series
window and trains an affine head to predict its membership at each valid token.
The auxiliary loss is added to the host's native self-supervised objective.
The auxiliary head is discarded for downstream inference.

This repository covers the paper's principal native versus native + TRD
comparisons: **TS2Vec, PatchTST and PMT on CirCor and OpenPack**, with both
frozen readouts and both fitting-label budgets. Six explicit profiles cover
36 pretraining runs across seeds 42, 7 and 123.

The code passes synthetic tests and small CPU comparisons against the research
implementation. Full 200k-update experiments have not been rerun with this package.
Supporting studies and additional baselines are outside this release.

## Installation and checks

Python 3.11 and PyTorch 2.10 are the reference versions. On a machine where
environment installation is permitted:

```bash
python -m pip install -e '.[dev]'
python -m pytest -q
```

Choose the appropriate PyTorch CPU/CUDA distribution for the machine. The full
TS2Vec/CirCor paper profile uses about 31.5 GiB peak allocated GPU memory in the
reported benchmark; synthetic checks and small examples have different costs.

## Prepare data

Download CirCor 1.0.3 from
[PhysioNet](https://physionet.org/content/circor-heart-sound/1.0.3/), retaining
the original ZIP with its checksums and metadata:

```bash
python -m trd.prepare --dataset circor --archive downloads/circor.zip \
  --extract-to data/circor_source --output data/circor
```

For already extracted data, replace `--archive` and `--extract-to` with
`--source` pointing to the directory containing `training_data.csv`.

Download and prepare the original [OpenPack 1.0.0 release](https://zenodo.org/records/8145223):

```bash
python -m trd.download_openpack --output data/openpack_source --workers 2
python -m trd.prepare --dataset openpack --source data/openpack_source \
  --output data/openpack
```

The downloader verifies all 21 participant archives. Preparation requires its
`source_manifest.json`; the tutorial archive of precombined IMU/labels uses a
different format. Both adapters verify source integrity and keep linked
identities together. Prepared directories must be new.

| Dataset | Input | Train / validation / test |
| --- | --- | --- |
| CirCor | 4 s, 4 kHz, one channel | 2,212 / 486 / 465 recordings; 610 / 130 / 132 groups |
| OpenPack | 60 s, 30 Hz, left-wrist acceleration | 70 / 14 / 20 sessions; 10 / 3 / 3 people |

[Split manifests](splits/) contain the paper's public recording IDs and group
assignments. Data and outputs remain local and are ignored by Git.

## Train and evaluate

For one PMT/CirCor encoder:

```bash
python -m trd.train --config configs/circor/pmt.yaml --data data/circor \
  --mode trd --seed 42 --output runs/circor_pmt_trd_42
python -m trd.probe --checkpoint runs/circor_pmt_trd_42/step_200000.pt \
  --data data/circor --output runs/circor_pmt_trd_42/heads --cache runs/cache
python -m trd.evaluate --checkpoint runs/circor_pmt_trd_42/step_200000.pt \
  --data data/circor --heads runs/circor_pmt_trd_42/heads \
  --output runs/circor_pmt_trd_42/test.json --cache runs/cache
```

Use `--mode native` for the matched control. Repeat with seeds `42`, `7`, `123`,
the three host profiles and both datasets. Probe fitting uses training and
validation only; test evaluation reuses the saved heads and feature scaling.
Use `--updates 10` for a short training check; it preserves the 200k schedule.
CPU checks use `--device cpu`.

Both heads and fitting budgets are fitted by `trd.probe`: 7/31 training groups
on CirCor, or 1/5 labeled minutes per training person on OpenPack. Epoch selection
uses the full validation partition. Scores are typed-onset macro-F1 at 50 ms
for CirCor and supported operation macro-F1 at 1 Hz for OpenPack.

Use a new output directory for each run. Checkpoints support inference and
probing; training resume is not implemented. Give `--cache` sufficient space
for temporary feature banks, which are deleted after probing. Training supports
`--threads` to set CPU parallelism. Profiles pin the paper's settings and full
schedule; see the manuscript for detailed numerical and selection conventions.

## Reported results

[Reference scores](results/reference_scores.csv) contain 144 per-seed test
scores from the original experiments. They are reference data, not outputs
generated by this extraction. Recreate the paired tables with:

```bash
python -m trd.summarize --csv results/reference_scores.csv
```

To aggregate new runs, pass their `test.json` files using `--results` instead.
The summarizer requires complete matched seeds and the fixed 200k endpoint.
Raw data and pretrained weights are not bundled.
